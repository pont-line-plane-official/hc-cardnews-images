MBTI 16유형별
좋아하는 질문 · 하면 안 되는 질문

「MBTI가 어떻게 되세요?」 「저 INFP요…!」 「아! 그러시구나!」 「……」

여기서 대화가 끝나버린 적 있으시죠. 그럴 때 쓰라고 16유형 전부 정리했어요.

정답은 없어요. MBTI가 맞냐 틀리냐도 상관없고요. 어떤 유형이든 자기 얘기할 때 제일 신나요. 그 질문 하나를 던져주면 됩니다.

유형마다 좋아하는 질문 두 개, 그리고 하면 안 되는 질문 하나.

쓰는 법

  • 상대가 말한 유형을 찾아서 좋아하는 질문 중 하나만 던지세요. 둘 다 할 필요 없어요.
  • 「하면 안 되는 질문」은 그 유형이 제일 방어적이 되는 말이에요. 초반엔 피하세요.
  • 답이 나오면 「그건 어쩌다요?」 한 번 더. 그게 대화를 이어갑니다.

근데 이걸 어디서 써보죠?

소개팅이 자주 있는 것도 아니고, 처음 만난 사람이랑 MBTI 얘기까지 가는 것도 쉽지 않죠.

하트커넥트는 대화를 통해 결이 맞는 사람을 찾아가는 블라인드 연애 프로그램이에요. 질문에 답을 쓰고, 답변만 보고 결이 맞는 사람을 골라요. 이 질문들 써먹을 자리가 매일 생깁니다.

I로 시작하는 유형

혼자 있는 시간이 충전인 사람들. 처음엔 말수가 적어도 자기 얘기가 나오면 길어져요

ISTJ

좋아하는 질문 — 요즘 꾸준히 지키고 있는 루틴 있어요? / 제일 믿고 쓰는 물건이나 방법 있어요? 하면 안 되는 질문 — 「그냥 즉흥적으로 가요!」 — 계획 없이 끌고 가기

ISFJ

좋아하는 질문 — 요즘 제일 챙기게 되는 사람 있어요? / 어릴 때 좋아한 거 아직도 좋아해요? 하면 안 되는 질문 — 「왜 그렇게 남 눈치를 봐요?」

INFJ

좋아하는 질문 — 요즘 마음에 오래 남은 말 있어요? / 사람들이 잘 모르는 내 모습 있어요? 하면 안 되는 질문 — 「그건 너무 깊게 생각하는 거 아니에요?」

INTJ

좋아하는 질문 — 요즘 혼자 세워둔 계획 있어요? / 다들 하는데 나는 안 하는 거 있어요? 하면 안 되는 질문 — 「그냥 대충 해도 되잖아요」

ISTP

좋아하는 질문 — 최근에 직접 고치거나 만들어본 거 있어요? / 손으로 하는 것 중에 제일 잘하는 거? 하면 안 되는 질문 — 「지금 기분이 정확히 어때요?」 — 감정 캐묻기

ISFP

좋아하는 질문 — 요즘 제일 예쁘다고 느낀 순간이 언제예요? / 나만 아는 좋은 곳 있어요? 하면 안 되는 질문 — 「그래서 결론이 뭐예요?」

INFP

좋아하는 질문 — 요즘 혼자 오래 생각하게 되는 게 있어요? / 어떤 얘기 들으면 울컥해요? 하면 안 되는 질문 — 「그게 현실적으로 되겠어요?」

INTP

좋아하는 질문 — 요즘 파고드는 주제 있어요? / 남들은 이상하다는데 나는 재밌는 거? 하면 안 되는 질문 — 「그래서 언제까지 할 건데요?」

질문을 던지고 기다려주세요. I는 답을 고르는 시간이 좀 길어요. 그 침묵을 채우려고 다음 질문을 던지면 대화가 끊깁니다.

E로 시작하는 유형

사람이랑 있을 때 충전되는 사람들. 질문 하나에 세 가지가 나와요

ESTP

좋아하는 질문 — 최근에 충동적으로 한 것 중에 제일 잘한 거? / 지금 당장 하고 싶은 거 있어요? 하면 안 되는 질문 — 「5년 뒤 계획이 뭐예요?」

ESFP

좋아하는 질문 — 요즘 제일 재밌었던 날이 언제예요? / 요즘 빠진 노래나 사람 있어요? 하면 안 되는 질문 — 「좀 진지하게 얘기해봐요」

ENFP

좋아하는 질문 — 요즘 갑자기 꽂힌 거 있어요? / 요즘 만나고 싶은 사람 있어요? 하면 안 되는 질문 — 「저번에 시작한 건 어떻게 됐어요?」

ENTP

좋아하는 질문 — 요즘 남들이랑 의견 다른 거 있어요? / 세상에서 제일 이상한 규칙이 뭐 같아요? 하면 안 되는 질문 — 「그냥 하라는 대로 하면 안 돼요?」

ESTJ

좋아하는 질문 — 요즘 제일 잘 돌아가고 있는 일이 뭐예요? / 다른 사람은 못 하는데 나는 되는 거? 하면 안 되는 질문 — 「계획 없이 그냥 가보면 어때요?」

ESFJ

좋아하는 질문 — 요즘 누구 챙기느라 바빠요? / 사람들이 나한테 제일 자주 부탁하는 게 뭐예요? 하면 안 되는 질문 — 「혼자 다니는 게 더 편하지 않아요?」

ENFJ

좋아하는 질문 — 요즘 누구 응원하고 있어요? / 사람들이 나한테 고민 털어놓는 편이에요? 하면 안 되는 질문 — 「남 신경 그만 쓰고 자기나 챙겨요」

ENTJ

좋아하는 질문 — 올해 꼭 이루고 싶은 거 하나만 꼽으면? / 사람들이 나한테 제일 많이 하는 오해는? 하면 안 되는 질문 — 「그렇게까지 할 필요 있어요?」

E한테는 이어 묻기만 하면 돼요. 첫 답이 나오면 「그건 어쩌다요?」 한 번이면 다음 10분이 채워집니다.

16유형 다 보셨네요 🙂

이제 물어볼 사람만 있으면 되겠어요.

하트커넥트는 대화로 먼저 만나요.
회차가 열리면 질문에 답을 쓰고,
답변만 보고 결이 맞는 사람을 고르는 ‘블라인드 픽’을 해요.

자기 얘기할 때 제일 신나는 사람들, 여기 모여 있어요 +_+
